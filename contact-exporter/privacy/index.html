Contact Exporter for WA Web

Privacy Policy

Last updated: November 18, 2026

In short: Contact Exporter for WA Web does not collect, store or send any data.

What data is accessed?

When you click the extension icon while the active tab is web.whatsapp.com, the extension reads the contact list (names and phone numbers) that WhatsApp Web keeps locally in your browser. It does not access your messages, chats or media files.

What happens to the data?

  • The contact list is held in memory only while the extension window is open, and is discarded when it closes.
  • The CSV/VCF files you export are downloaded directly to your computer.
  • The extension connects to no server, contains no analytics or tracking tools, and never shares or sells data.
  • Your number format preference is saved only in your browser, inside the extension's own storage.
  • The source code is open, so anyone can verify these statements.

Permissions

  • activeTab: access only to the tab you click the icon on, only at that moment.
  • scripting: to run the function that reads the contact list in that tab.

Affiliation

This extension is not affiliated with WhatsApp LLC or Meta Platforms.
